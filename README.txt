JUMPL4Y — DEMO VISUAL PARA NETLIFY
===================================

Archivos:
- index.html
- styles.css
- script.js

PUBLICACIÓN MÁS RÁPIDA
1. Abre https://app.netlify.com/drop
2. Arrastra la carpeta 'jumpl4y-demo' completa (descomprimida).
3. Netlify generará una URL pública para compartir al cliente.

Alternativa: sube el ZIP en Netlify si tu interfaz lo permite; Netlify Drop normalmente espera una carpeta descomprimida.

IMPORTANTE
- Es un prototipo HTML/CSS/JS; no necesita npm ni servidor.
- Las noticias son ejemplos ficticios y reemplazables por contenido real.
- El botón 'Ver todo', las tarjetas, el buscador y el menú móvil son interactivos.
- El formulario es visual: NO guarda suscripciones.
- Las fotos se cargan desde Unsplash y necesitan conexión a Internet.
- No se implementó reproducción de video/GIF reales porque necesitarán archivos o URLs aprobadas por el cliente.
- No es un tema WordPress; sirve para aprobar diseño antes de construirlo.
